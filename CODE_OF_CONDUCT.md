# Contributor Covenant Code of Conduct

> **Language**: **English** | [Tiếng Việt](docs/vi/CODE_OF_CONDUCT.md)

## 1. Our Pledge
As maintainers and contributors to **KSU Ultimate Gaming X**, we pledge to foster an open, welcoming, honest, and harassment-free community experience for everyone — from newcomers learning about Android/KernelSU to experienced kernel developers.

## 2. Expected Behavior
- Use welcoming, respectful, and constructive language in Issues, Pull Requests, and commit feedback.
- **Be strictly honest about verification results**: distinguish physical hardware testing from mock/emulator testing, and never fabricate compatibility claims or benchmarks.
- Protect user privacy: use `kgxctl diag` to redact serial numbers, IMEIs, MAC addresses, IP addresses, and tokens before sharing logs publicly.
- Respect the project's **GNU GPL v3.0 or later (`GPL-3.0-or-later`)** license, third-party copyright notices ([NOTICE](NOTICE)), and AI disclosure guidelines ([AI_CONTRIBUTIONS.md](AI_CONTRIBUTIONS.md)).

## 3. Unacceptable Behavior
- Harassment, insults, discrimination, or personal attacks against community members.
- Publishing other people's private data (doxxing), secrets, tokens, keystores, or unredacted user logs.
- Submitting malicious code, destructive sysfs/hardware modifications, or unreviewed bulk AI spam ("AI slop").
- Impersonating project maintainers, Google staff, or third-party developers.

## 4. Scope & Enforcement
This Code of Conduct applies across all project spaces (GitHub Issues, Pull Requests, Discussions, and comments). Instances of abusive or unacceptable behavior may be reported to the project maintainer **`hangothanhh`** via GitHub Issues or public contact channels listed on https://github.com/hangothanhh. Maintainers retain the right to remove or edit non-compliant comments, close offending Issues/PRs, or restrict participation for serious or repeated violations.
